# Multi-vehicle reference core

The new vehicle_models module provides a registry with differential drive, Ackermann bicycle, omnidirectional, multirotor and fixed-wing reference kinematics. Turn means steering angle for Ackermann and yaw rate for other built-in models. Profiles are external JSON; the sample profiles are illustrative, not certified limits. The registry accepts additional callable models. The fleet module is transport-neutral, supports arbitrary member IDs and capability sets, one task per available member, deterministic priority/distance assignment, reassignment when telemetry expires, and 3D pairwise constant-velocity conflict prediction with radius and uncertainty. Stale peers are explicit unknowns. All timestamps must use a common clock and positions a common frame.

No actuator commands are produced. This is not a distributed consensus protocol, production driving stack, road/lane planner, full vehicle dynamics, 3D obstacle planner or certified safety system. The existing navigation module still uses unicycle sampling; the new registry is not yet wired into that planner, ROS, CARLA or C++ RTA. Maritime and VTOL require additional models. Run tests with docker compose run --build --rm test.
